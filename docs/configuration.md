# Configuration

All settings are environment variables loaded via `app/core/config.py`; see
`.env.example` for the full list and defaults, including the Acumatica block
(`ACUMATICA_BASE_URL`, `ACUMATICA_USERNAME`, `ACUMATICA_PASSWORD`,
`ACUMATICA_TENANT`, `ACUMATICA_BRANCH`, `ACUMATICA_PRODUCTS_GI`,
`ACUMATICA_SALES_GI`).
